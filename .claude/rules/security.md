# 보안 · 인증 규칙

## P0
- **시크릿 하드코딩 금지**: API 키·DB 비번·토큰을 소스·설정(`application.yml`, `.env`)·로그·커밋
  메시지에 넣지 않는다. `[자동강제: pre-commit(.env 차단 상시·gitleaks 설치 시 정밀 스캔)]`
  오탐은 `.gitleaks.toml` allowlist 에 근거와 함께 추가.
- **인증 없는 엔드포인트 금지**: 로그인·정적 페이지 외 모든 비즈니스 API 는 인증/세션 체크 필수.
  관리자 API 는 명시적 require-admin 패턴.
- **파괴적 DB API 금지**: `DELETE/DROP/TRUNCATE` 를 수행하는 API 를 제공하지 않는다.
  필요 시 사용자 명시 동의.

## 프론트
- **public/번들 환경변수에 시크릿 금지** (`NEXT_PUBLIC_*`, `VITE_*` 등) — 번들에 평문 포함되어
  브라우저에 노출된다. 시크릿이 필요한 호출은 백엔드 경유.
- 토큰·세션 값을 `console.log`·에러 메시지·쿼리스트링에 노출 금지.

## 백엔드
- **외부 API 자격증명은 secret store 또는 DB 동적 조회** — 코드에 키 보관 금지.
- **로그인 브루트포스 록아웃**: 최대 시도 횟수/잠금 시간은 설정값으로(합리적 기본값, 예: 5회/5분).
- **초기 관리자 주입**: 관리자 자격증명 환경변수가 있을 때만 기동 시 1회 생성(중복 검사 필수).
  환경변수 없으면(로컬 등) 자동 생성 금지.
