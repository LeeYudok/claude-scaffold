# 데이터 스크립트 규칙 (data/)

외부/공공 데이터 수집·정제·적재 파이썬 스크립트 기준.

## P0
- **대용량 데이터 Git 스테이징 금지**: `data/` 이하 원본/정제 파일(*.csv, *.xls, 임시 import
  디렉터리) 커밋 절대 금지. 파일 삭제·경로 변경 시 `.gitignore` 규칙 유지 확인.

## P1
- **인코딩**: 외부/공공기관 CSV 는 legacy 인코딩(`cp949`/`euc-kr` 등)이 많다 — 읽기 시
  인코딩 명시(`encoding=...`), 최종 적재 파일은 `utf-8` 통일.
- **메모리**: 대용량 CSV 는 `readlines()` 같은 전체 적재 금지 — 라인 제네레이터/청크 처리로
  OOM 방지.
- **키 필드 선검증**: 키 필드 포맷부터 확인, 비정상 행은 skip 처리(+건수 집계).
- **진행 로그**: 처리/스킵/성공·실패 건수를 콘솔에 출력 — 예:
  `print(f"{basename}: kept={n} skipped={s} -> {out}")`.

## P2
- 중간 가공 임시 파일은 gitignore 된 임시 디렉터리(예: `data/.import_tmp/`)에 격리.
